# `pr/esp32-coredump`

One part of the topic repo p1ngb4ck/esphome-esp32-platform. The whole topic, with its description, is the branch `main`.

Change of this branch: crash dumps to a `coredump` partition, API actions `coredump_info` / `coredump_read` / `coredump_erase`

Based on these branches, whose changes it holds and builds on:

- `pr/esp32-chip-revision`: ESP32-P4 `minimum_chip_revision`, settings from the detected chip revision, API action `chip_revision`
